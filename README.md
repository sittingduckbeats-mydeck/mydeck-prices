# MYDECK Preise

Holt einmal pro Woche (montags) die Marktpreise aller Pokémon-Karten aus der kostenlosen TCGdex-Datenbank
(Cardmarket in EUR, TCGplayer in USD) und speichert sie in `data/prices.json`.
MYDECK liest diese Datei und zeigt die Preise im Poké-Archiv.

Manuell starten: Tab **Actions** → **Preise abrufen** → **Run workflow**.
